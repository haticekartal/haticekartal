## About

<img align="right" width="300" alt="Illustration of a Python and AI instructor working at her desk" src="https://raw.githubusercontent.com/haticekartal/haticekartal/main/assets/python_ai_readme.gif" />

I teach Python programming and applied artificial intelligence. This profile hosts the example code from my courses: short, runnable programs with explanatory comments in Turkish, organized so that learners can follow each topic step by step.

- **Teaching areas:** Python fundamentals, object-oriented programming, machine learning, neural networks
- **Approach:** one concept per example, starting simple and building toward small projects
- **Materials:** course code is published openly here on GitHub
